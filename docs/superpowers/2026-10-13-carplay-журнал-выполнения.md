## 2026-10-15 — шесть замечаний из машины: причины и что сделано

Замечания: (1) без деления «ждёт/не ждёт» — пространство → чаты → сообщения; (2) сообщения пузырями; (3) «Голос» и Mute ничего не делают; (4) повторный тап по сообщению должен останавливать чтение; (5) тестировать локально, а не в машине; (6) «Голос» не включает прослушивание.

**Корень (3) и (6), с доказательством из лога демона.** Все экраны чата создавались с одним id `"chat"` и никогда не уничтожались. Нативное хранилище держит шаблоны по id (новый перезаписывает старый), а JS-слушатели каждого экземпляра фильтруют события по тому же id — так одно нажатие «Голос» срабатывало во всех открытых за поездку чатах, каждый для своего агента. В `~/.paseo/daemon.log` 16:43:55 с телефона за 140 мс пришли четыре `set_voice_mode` для трёх агентов; демон запутался и оставил у агентов «висячие» `voiceSpeakHandlers` → с тех пор любой запуск голоса для них отвечает «Voice mode is already active for this agent» с любого устройства (до `paseo restart`). Старый интерфейс показывал это как «Нет связи с демоном». Mute с двумя живыми обработчиками включался и тут же выключался. Плюс автостарт голоса при открытии чата звал `startVoice` для уже активного агента.

**Что сделано** (`packages/app/src/carplay`, 82 теста):

- Три экрана: проекты (`projectRows`, группировка по `projectId`, не по пространству — у человека пространство = один чат с авто-заголовком вроде «продолжай») → чаты проекта (плоский список по свежести, состояние первым словом подзаголовка) → сообщения. У каждого экземпляра шаблона свой id (`chats-N`, `chat-N`); «Назад»/`poppedToRoot` уничтожают шаблон, выключают голос и чтение, снимают подписку таймлайна.
- Пузыри: CarPlay рисует только системные строки; слева плашка автора (`assets/bubble-*.png`, фиолетовый — агент, серый — человек), сгенерированы PIL. `headline()` дополнительно вырезает markdown-картинки/ссылки и любые `scheme://`.
- Голос только кнопкой; открытие чата микрофон не трогает. Подписи кнопок меняются через нативный `updateListTemplate` («Голос/Стоп», «Mute/Звук»). Шапка: «Включаю…», «Слушаю…», …, ошибки словами: «Разреши микрофон на телефоне», «Нет связи с компьютером», «Голос уже включён на другом устройстве», «Голос не включился» — и ошибка держится, пока человек не попробует снова. Повторное нажатие во время запуска игнорируется (двойной тап в симуляторе давал два параллельных `startVoice`, первый из которых рантайм выбрасывал по поколению).
- Чтение: `createReader` с `onDone/onStopped/onError`, язык по алфавиту; повторный тап останавливает; строка помечена `isPlaying`; при включённом голосе микрофон глушится на время чтения (иначе прочитанное идёт в машинный микрофон как речь водителя) и возвращается после.
- Контроллер держит `acquireDirectoryDemand` для всех хостов, пока машина подключена: каталог агентов в приложении грузится только по требованию экрана, и без своего спроса CarPlay видел «Чатов пока нет» при десятке чатов (на телефоне спрос случайно держала боковая панель).
